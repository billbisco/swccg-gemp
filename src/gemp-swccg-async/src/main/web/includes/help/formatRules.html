Format Definitions

A 'format' is a shorthand for what cards are legal to use and what deck-building rules apply. Every format that can be played in the Game Hall is listed below; click a format's name to see its definition. i

  • Deck size: how many cards a deck must have in this format.
  • Default game timer: the time each player gets on their clock when a table is opened in this format, unless the table's creator changes it.
  • Valid sets: the sets whose cards can be used. "All sets valid" means every set the game has had, Virtual sets included.
  • Banned (X-listed) cards cannot be used at all; restricted (R-listed) cards are limited to one copy.
The SWCCG Wiki has the full text of each format's rules.
