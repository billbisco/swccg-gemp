League schedules i

A schedule creates leagues on its own: the same settings, an ordered rotation of events (each with its own format or series), and a cadence. Each league is created a number of days before it starts so players can sign up. A schedule is off until you enable it; the Events calendar shows what an enabled schedule will create as "Scheduled (not yet created)". Upcoming lists the next leagues; Create next now makes the next one at once and moves the schedule on.

Cost (silver) i
What a player pays to join, in silver (100 silver = 1 gold). 0 makes the league free.
Start date i
The day the first serie opens for play (server time). Players can sign up as soon as the league exists, and the league stays listed for two days after its last serie ends.

Players cannot join by themselves; add them with "Add players to league" at the bottom of this page. The registration info below tells them how to get in.

Collection i
"All cards" lets players build from every card in the game; "My cards" restricts them to the cards they own.
Deck lock-in i
With locking, the first deck a player uses for each side is the one they must keep for the whole league; admins can read the locked decks from the league's page.
Format i
A sealed league has one serie per pack of its product: the days and the match limit apply to each. Players open their packs when they join. A draft league has one serie; players draft their pool from the hall once it has started. The days and the match limit apply to the serie. Each serie runs for the given number of days, one after the other, in its own format; only the first "max matches" ranked games count per player in each.
The hall's format list has not loaded, so the formats offered here are this page's own copy.
Series name i
The name of the whole schedule; it fills {series} in the league name pattern below.
League name pattern i
How each created league is named. Tokens: {series} the series name, {event} the event name, {month} November, {mon} Nov, {mm} 11, {year} 2026, {yy} 26. The result must be 45 characters or less, and a league with the same name must not still be running when the next one is due, so a monthly schedule usually wants {month} {year} in it.
Repeat every i
Whole months keep the day of the month (the 1st stays the 1st). 0.25 = weekly, 0.5 = every two weeks, 1.5 = a month and two weeks.
Create i
Each league appears in the hall this many days before it starts, so players can sign up in advance. An occurrence whose start is already more than two days gone is skipped, never created.
Enabled i
Off: the schedule is stored and can be previewed, but creates nothing. On: the server creates its leagues, starting right away with any that are within the lead time.
Rotation i
The events the schedule cycles through, in order; after the last one it starts again from the first. Each event has its own format(s); everything else above (cost, timers, collection, lock-in) is shared by every event. The event marked "next" is the one created next.
