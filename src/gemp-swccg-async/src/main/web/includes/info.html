About

GEMP is a general-purpose game engine for trading card games. This one plays the Star Wars Customizable Card Game; there is also one for the Lord of the Rings TCG, whose code this hall's layout is adapted from.

GEMP was originally written by MarcinS, who started the project in 2011. The Star Wars CCG version is maintained by the community; its code is on GitHub, and so is the list of open bugs and requests.

Card images and rules text are the property of Lucasfilm Ltd and Decipher, Inc. This site is not produced, endorsed, supported or affiliated with either.
