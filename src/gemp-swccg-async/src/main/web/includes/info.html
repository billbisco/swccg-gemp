About

GEMP is a general-purpose game engine for trading card games. This instance plays the Star Wars Customizable Card Game; another plays the Lord of the Rings TCG, and this hall's layout is adapted from that one.

GEMP was originally built to emulate Legend of the Five Rings, which is where the name comes from: Gempukku, a coming-of-age ceremony in Japanese, was meant to mirror the Apprentice program for Magic: the Gathering.

MarcinS created GEMP and started the project in August 2011. The Star Wars CCG version was built on it by volunteers from the SWCCG community and has been maintained by them since.

GEMP is written with a Java and MySQL back end and a framework-less JavaScript front end. The code is on GitHub, with the list of everyone who has contributed to it and the open bugs and requests.

Card images and rules text are the property of Lucasfilm Ltd and Decipher, Inc. This site is not produced, endorsed, supported or affiliated with either.
