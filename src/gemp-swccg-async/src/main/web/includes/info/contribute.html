How can I help?

You can contribute in several ways:

  • First, by playing! The more people there are in the hall, the easier it is for anyone to find a game or get help, and the more games are played, the sooner the odd card bug shows itself.
  • By reporting what goes wrong. If a card does not do what its text says, or the site misbehaves, open an issue on GitHub (the Report a Bug button at the top of the Game Hall takes you there). Say which cards were involved and what you expected to happen; the game id from the game window helps a lot.
  • If you are a programmer (or would like to become one), GEMP's code is on GitHub. Pull requests are welcome, from a one-line card fix to a new part of the site. The issue list is a good place to find something to start on, and to say what you are working on so that nobody does it twice.
  • If you are interested in playtesting, say so in the hall chat or in an issue: playtesters see the playtesting formats in the hall, where new virtual cards and errata are tried out before they are released, and we can always use more people trying things out.
  • If you would rather write than code, the SWCCG Wiki is where the rules, the cards and the formats are explained, and it always has pages that could use another pair of hands.
